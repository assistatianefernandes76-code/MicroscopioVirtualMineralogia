# Microscópio Virtual de Mineralogia

Projeto para desenvolvimento de um simulador mineralógico interativo baseado em grãos gerados por diagramas de Voronoi.

## Objetivos

- Simular seções polidas
- Treinar identificação mineralógica
- Avaliar grau de liberação
- Desenvolver ferramentas educacionais para mineralogia

## Minerais iniciais

- HM
- HE
- Magnetita
- Goethita
- Quartzo
